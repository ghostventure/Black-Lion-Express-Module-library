# Black Lion Express Module library

A library for reusable software modules.

## LionMax Universal Logon

[LionMax Universal Logon](lionmax-universal-logon/) is a standalone three-field sign-in service with an OpenID Connect interface for other applications. It includes a separate demonstration application, a five-attempt account lock, and IP-based token-attempt history. The module README explains local operation, integration, and production requirements.

The [Windows desktop release](https://github.com/ghostventure/Black-Lion-Express-Module-library/releases/tag/lionmax-v0.3.0) opens in its own dark-themed window and includes Microsoft 365, Google Workspace, Slack and configurable proprietary OIDC connectors. Provider setup requirements and the persistent per-user connection database are documented in the module. Extract the complete ZIP and launch **LionMax.exe**.
